# TranscribeAndTranslate

# 📜 Генерация и перевод субтитров для видео

Этот скрипт предназначен для автоматической генерации субтитров к видеофайлам с последующим переводом на русский язык. Он использует API Groq для транскрипции аудио и утилиту `trans` для перевода текста. Скрипт создает файл субтитров в формате SRT.

## 🚀 Возможности

- **Транскрипция аудио**: Извлекает аудиодорожку из видеофайла и преобразует её в текст с помощью модели Whisper (через Groq API).
- **Перевод субтитров**: Переводит сгенерированные субтитры с английского на русский язык.
- **Автоматизация**: Проверяет наличие необходимых инструментов и обрабатывает ошибки.
- **Поддержка прокси**: Возможность использования SOCKS5-прокси для сетевых запросов.
- **С помощью напильника и кувалды**: 🛠️ Можно добавить ещё массу фич. Код открыт. Всё в ваших руках.

## 📋 Требования

Для работы скрипта необходимы следующие зависимости и утилиты:

- **Node.js** (версия 14 или выше)
- **FFmpeg**: Для конвертации видео в аудио (MP3).
- **Translate-shell (trans)**: Для перевода текста субтитров.
- **Groq SDK**: Для доступа к API транскрипции.
- **Переменные окружения**:
  - `GROQ_API_KEY`: Ваш API-ключ Groq.
  - `SOCKS5` (опционально): Адрес SOCKS5-прокси (например, `socks5://host:port`).

### Установка зависимостей

1. Установите Node.js: [Скачать](https://nodejs.org/).
2. Установите FFmpeg:
   - Linux: `sudo apt-get install ffmpeg`
   - macOS: `brew install ffmpeg`
   - Windows: [Скачать](https://ffmpeg.org/download.html)
3. Установите Translate-shell:
   - `npm install -g translate-shell` или [инструкция](https://github.com/soimort/translate-shell).
4. Установите зависимости проекта:
   ```bash
   npm install
   ```

## ⚙️ Установка и настройка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/mirninec/TranscribeAndTranslate.git
   cd TranscribeAndTranslate
   ```

2. **Создайте файл `.env`** в корне проекта и добавьте необходимые переменные:
   ```env
   GROQ_API_KEY=ваш_ключ_api
   SOCKS5=socks5://хост:порт (опционально)
   ```

3. **Убедитесь, что FFmpeg и trans доступны**:
   ```bash
   ffmpeg -version
   trans --version
   ```

## 🛠️ Использование

Запустите скрипт, указав путь к видеофайлу:

```bash
node subtitle-rus.mjs путь/к/видео.mp4
```

### Пример

```bash
node subtitle-rus.mjs ./videos/sample.mp4
```

Скрипт:
1. Извлечет аудио из `sample.mp4` и сохранит его как `sample.mp3`.
2. Транскрибирует аудио в субтитры (на английском).
3. Переведет субтитры на русский язык.
4. Сохранит результат как `sample.srt` в той же папке.
5. Удалит временные файлы (`sample.mp3`, временный SRT).

### Вывод

- Если субтитры уже существуют, скрипт сообщит об этом и завершит работу.
- В случае ошибок (например, отсутствие файла или утилит) будут выведены соответствующие сообщения.

## ⚠️ Возможные проблемы и решения

- **Ошибка "ffmpeg не найден"**: Убедитесь, что FFmpeg установлен и добавлен в PATH.
- **Ошибка "trans не найден"**: Установите Translate-shell и проверьте его доступность.
- **Ошибка API Groq**: Проверьте правильность `GROQ_API_KEY` и подключение к интернету.
- **Проблемы с прокси**: Убедитесь, что SOCKS5-прокси работает, или удалите переменную `SOCKS5`.
